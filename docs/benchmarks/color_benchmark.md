## Conclusion

Identical protocol (frozen ImageNet backbone + trained linear head, 20 epochs)
so the comparison is fair. **EfficientNet-B0 has the best accuracy/macro-F1**
(0.624 / 0.627) but the worst CPU latency (281 ms) — its many small depthwise
ops are slow on CPU. **ResNet50** trails on accuracy despite 23.5 M params and
is by far the largest (94 MB). **MobileNetV3-Small** sits within ~3 pts of the
best accuracy at **a quarter of EfficientNet's size (6.24 MB) and ~3× lower
latency** — the best accuracy↔cost trade-off for the edge/CPU target.

### CCTV domain adaptation (earlier runtime model — replaced, see note above)

The frozen-head models above were trained on clean `car_colors` photos and
**failed on real garage CCTV** — washed-out under fluorescent light, they
predicted "Blue" for both a black and a white car. Re-running with
**domain-randomisation augmentation** (CCTV-mimicking blur + brightness/
contrast/saturation jitter + random downscale; `scripts/retrain_color.py`)
fixed the known cases: the black car → **Black (0.55)** and the white car →
**White (0.67)**. This augmented MobileNetV3-Small **used to be** the model
shipped at runtime (`color_MobileNetV3Small.pt`). Clean-val accuracy dips
slightly (0.60 → 0.52) because augmentation makes the clean set harder, but
real-CCTV behaviour was qualitatively correct.

**Selected at the time: MobileNetV3-Small** (matches the model wired into the
pipeline back then). Absolute accuracy (~55-60%) was modest because only the
head was trained on an imbalanced 8-class set (Yellow 25, Brown 35 images) —
unfreezing the backbone or class-balanced sampling were flagged as the next
levers. **Both were applied later** (full backbone fine-tune + the VCoR
dataset merge, 5,881 images, class-weighted loss + label smoothing + TTA),
lifting test accuracy to the current deployed **86.3% TTA** — see the
superseded-note at the top of this file for the current numbers. Trained on
Apple M1 Max (MPS); TensorFlow `model.fit` was abandoned after it deadlocked
at 0% CPU on this macOS build (oneDNN threadpool), so the benchmark uses
PyTorch/torchvision.
