# Course Summary: DPL302m - Deep Learning (Học sâu)

This document provides a structured, concise summary of the DPL302m course syllabus for quick reference by agents and developers.

---

## 1. General Course Information
* **Subject Code:** DPL302m
* **Syllabus ID:** 13339
* **Degree Level:** Bachelor
* **Credits:** 6
* **Pre-requisite:** AIL303m (Machine Learning)
* **Time Allocation:** 300 hours total
  * 90 hours contact/class time
  * 209 hours self-study
  * 1 hour final exam
* **Key Tools:** Jupyter Notebook, TensorFlow/Keras, Cloud Servers (72 hours allocated per project).

---

## 2. Course Learning Outcomes (CLOs)
* **CLO1:** Build, train, and apply fully connected deep neural networks.
* **CLO2:** Train/develop test sets, analyze bias/variance, apply optimization, and use TensorFlow.
* **CLO3:** Diagnose errors in ML systems, analyze strategy, and apply transfer/multi-task learning.
* **CLO4:** Build CNN models for visual detection, recognition, and neural style transfer.
* **CLO5:** Build and train recurrent neural networks (RNNs/LSTMs), work with NLP, HuggingFace tokenizers, and Transformers.
* **CLO6:** Implement a Deep Learning project pipeline: Data Collection $\rightarrow$ Data Wrangling $\rightarrow$ EDA $\rightarrow$ Model Development $\rightarrow$ Model Evaluation $\rightarrow$ Reporting.
* **CLO7:** Understand how to apply AI tools to complete a mini-project.

---

## 3. Assessment & Grading Schema
To pass the course, students must satisfy:
1. Every on-going assessment score must be **$> 0$**.
2. Final Exam Score **$\ge 4$** (out of 10).
3. Final Course Average **$\ge 5$** (out of 10).

### Weight Breakdown:
| Component | Weight | Format | Scope / Description |
| :--- | :--- | :--- | :--- |
| **Report 1: Project Proposal** | 10.0% | Oral Group Presentation | Project selection, goals, and framework. Covers Ch. 1. |
| **Report 2: Data Tasks** | 10.0% | Oral Group Presentation | Data collection, cleaning, wrangling, and EDA. Covers Ch. 2. |
| **Report 3: Model & Results** | 30.0% | Oral Group Presentation | Model selection, training, hyperparameter tuning, results. Covers Ch. 3. |
| **Report 4: Final Report** | 10.0% | Group Presentation / Defense | Full project report, demo, and group defense. Covers Ch. 4. |
| **Progress Test** | 10.0% | 50 MCQs (60 mins) | Automated test covering chapters 1, 2, and 3. |
| **Final Exam** | 30.0% | 50 MCQs (60 mins) | Automated test covering chapters 1, 2, 3, and 4. |

## 4. Main Course Materials
The course follows the **DeepLearning.AI Deep Learning Specialization** on Coursera:
1. **Neural Networks and Deep Learning** (Course 1)
2. **Improving Deep Neural Networks:** Hyperparameter Tuning, Regularization, and Optimization (Course 2)
3. **Structuring Machine Learning Projects** (Course 3)
4. **Convolutional Neural Networks (CNNs)** (Course 4)
5. **Sequence Models (RNNs, LSTMs, Transformers)** (Course 5)

### Coursera Guided Projects referenced:
* GP 1: Diabetes Disease Detection with XG-Boost and Neural Networks
* GP 2: Hyperparameter Tuning with Keras Tuner
* GP 3: Object Localization with TensorFlow
* GP 4: NLP: Twitter Sentiment Analysis
